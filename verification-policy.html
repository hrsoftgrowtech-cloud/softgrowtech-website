DOCUMENT VERIFICATION

Verification Policy

How SoftGrowTech's public document-verification service is intended to work and be used responsibly.

Document VerificationPublic Record Access

1. Purpose

SoftGrowTech's document-verification service is provided to help users check whether a Student / Letter ID corresponds to an issued record.

2. Verification Details

The verification process may require the Student / Letter ID together with the last four digits of the registered mobile number. Both details are used to reduce accidental or unauthorized access to a record.

3. Verification Results

A successful verification may display the record information intended for public confirmation. Personal contact details are not intended to be unnecessarily exposed on the public verification result.

4. Failed Verification

If the supplied details do not match an issued record, verification may fail. If a matching record cannot be found, the user should review the details and use the available support option if assistance is required.

5. Responsible Use

  • Do not submit another person's information without authorization.
  • Do not attempt to bypass verification controls.
  • Do not use the verification service for scraping, harassment, fraud or unauthorized data collection.

6. Support

For a legitimate verification issue, use the Need Help / support option provided by SoftGrowTech or the contact details shown on the website.
