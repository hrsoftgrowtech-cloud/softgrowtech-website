Project Journey

Learn → Build → Evolve

Projects are a core part of the learning experience. Interns work on domain-relevant tasks with guidance from mentors, from understanding the idea to presenting the completed work.

📖

Learn the Concept

Understand the tools, concepts and project requirements before starting the implementation.

🛠️

Build the Project

Turn learning into practical work through guided tasks, hands-on implementation and problem solving.

👩‍🏫

Mentor Guidance

Mentors help explain project objectives, guide progress, review work and suggest improvements.

🚀

Evolve & Showcase

Refine the project, document your work and build confidence in explaining what you created.
